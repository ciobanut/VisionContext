# WordPress Image ALT Auto-Generator – Landing Page

This repository contains the landing page for a WordPress plugin that **automatically generates ALT text when images are uploaded**.

The goal of this landing page is to:
- validate demand
- collect emails for the private beta
- explain the core value in a simple, non-technical way

Built with **Astro.js** for speed, simplicity, and SEO.

---

## ✨ What this landing page does

- Presents the main problem: missing ALT tags in WordPress
- Explains the solution: automatic ALT generation on image upload
- Collects emails for early access / beta testing
- Focuses on conversion, not feature overload

This is **not** the plugin itself — only the pre-launch landing page.

---

## 🛠 Tech Stack

- **Astro.js**
- Static HTML rendering
- Minimal JavaScript
- SEO-friendly by default
- Optimized for performance and fast load times

## 🚀 Getting Started

### 1. Install dependencies
```bash
npm install
````

### 2. Start development server

```bash
npm run dev
```

The site will be available at:

```
http://localhost:4321
```

## 📦 Build for production

```bash
npm run build
```

Preview the production build locally:

```bash

```
